# Могилянський ранок

Щоденний медіамоніторинг спільноти НаУКМА: офіційні новини, згадки в медіа,
досягнення та публічні дописи випускників, співробітників і студентів.
Сторінка генерується щоранку GitHub Actions і публікується через GitHub Pages (`docs/`).

## Як це працює
1. **База людей** (`python -m mohyla.cli people`, щопонеділка): публічні могилянці з Wikidata
   (НаУКМА, kmbs, Могилянська школа журналістики) та категорій української Вікіпедії,
   разом із їхніми соцмережами. Ребра графа: спільний роботодавець, спільні згадки.
2. **Збір** (`python -m mohyla.cli daily`): RSS ukma.edu.ua, Google News (uk/en),
   публічні Telegram-канали (з конфігу, з профілів людей і знайдені в новинах);
   опційно Bluesky, Facebook (через Apify), LinkedIn/X/Threads (через Brave Search).
3. **Фільтр і зв'язування**: матеріал потрапляє в дайджест, якщо згадує Могилянку,
   знайдений за могилянським запитом (згадка в тексті статті), згадує відомого могилянця,
   або це власний допис могилянця про досягнення (не більше одного на людину).
4. **Снігова куля**: фрази на кшталт «випускниця Могилянки Ім'я Прізвище» додають кандидатів;
   після згадок у двох різних виданнях людина потрапляє до бази й до розділу
   «Нові могилянці в графі».
5. **Ранжування**: тип джерела, явна згадка, відомість людей, категорія
   (досягнення > наука > студентство > спільнота), свіжість. Дублікати зводяться в одну картку.

Налаштування (джерела, запити, канали, ключові слова, ваги) лежать у `config/sources.yaml`,
змінювати код не потрібно.

## Архів випускників (приватно)
`python -m mohyla.cli archive` збирає списки випускників 1995–2018 (18 випусків, ~8,7 тис. людей)
зі знімків Internet Archive сторінок alumni.ukma.edu.ua та ukma.kiev.ua і пише їх у
`data/private/people.json`. Це персональні дані приватних осіб, тому вони живуть в окремому
**приватному** репозиторії `mohyla-monitor-data`, а `data/private/` ігнорується тут.
Workflow підтягує його read-only deploy-ключем (секрет `DATA_REPO_SSH_KEY`); без ключа дайджест
працює лише з публічною базою. У публічних файлах випускники з архіву фігурують тільки як
непрозорі id (`alumni:<hash>`), а на сторінці з'являються лише тоді, коли їх уже назвали в
публічному матеріалі з контекстом Могилянки (чіп «випускник · ФЕН 2003»).
Відсутні в архіві: 2006–2007 (лише Flash), 2009–2010, 2017, 2019+.

## Запуск локально
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q
.venv/bin/python -m mohyla.cli people
.venv/bin/python -m mohyla.cli daily
```

## Публікація
1. Запушити репозиторій на GitHub.
2. Settings → Pages → Deploy from branch → `main` / `docs`.
3. Settings → Actions → General → Workflow permissions → Read and write.
4. Опційні секрети (Settings → Secrets → Actions), кожен вмикає своє джерело:
   `BSKY_HANDLE` + `BSKY_APP_PASSWORD`, `APIFY_TOKEN` (Facebook, платно, див. нижче),
   `TAVILY_API_KEY` (LinkedIn/X/Threads/Instagram через пошук Tavily, 1000 безкоштовних запитів на місяць).

## Facebook
Публічні сторінки (`facebook_pages`) і групи (`facebook_groups`) з `config/sources.yaml`,
профілі людей із бази та сторінки, знайдені за посиланнями в матеріалах дайджесту, збираються
двома запусками Apify на день. Витрати обмежені в конфігу: `facebook_max_charge_usd` (на кожен
запуск), `facebook_max_items`, `facebook_max_pages` / `facebook_max_groups`; фактична вартість
пишеться в лог кроку «Build daily digest». Особисті дописи потрапляють лише з позначкою «Публічно».

## Обмеження
- З 2025 року НаУКМА не веде офіційних Telegram-каналів, тож Telegram дає переважно
  особисті канали могилянців.
- Відмінювання імен покривається основами з закритим набором закінчень; чергування
  всередині слова («Ольга → Ользі») поки не розпізнається.
- Лише публічні особи та публічні дописи; зберігаються посилання та короткі фрагменти.
